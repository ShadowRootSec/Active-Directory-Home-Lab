# 🏢 Enterprise Active Directory Home Lab: From Zero to Admin

## 🎯 Project Objective
The objective of this project is to build a fully functional, enterprise-grade Active Directory (AD) infrastructure from scratch in a local virtualized environment. This repository serves as a complete educational guide, documenting not just *how* to set up AD, but *why* certain configurations are required. It is designed for cybersecurity students and IT enthusiasts to understand centralized identity management, Group Policies, and the foundation of enterprise networks.
