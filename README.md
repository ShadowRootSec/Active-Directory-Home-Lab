# 🏢 Active Directory Home Lab Setup

## 📌 Project Overview
Welcome to my Active Directory Home Lab. This project demonstrates the deployment and configuration of a local Active Directory environment using VMware Workstation. The goal was to simulate a real-world corporate network infrastructure to understand centralized identity management.

    *Installing AD DS and promoting the server to a Domain Controller (lab.local).*
3.  🔗 **[Phase 3: Managing Users & Groups](./03-Users-and-Groups.md)**

5.  🔗 **[Phase 5: Group Policy (GPO) Implementation](./05-Group-Policy-GPO.md)**
    *Creating and enforcing policies (e.g., blocking Control Panel) across the domain.*
